# Product App (Node.js · Express · MongoDB · EJS · Multer)

## Chạy ứng dụng
1. Cài MongoDB và đảm bảo đang chạy ở `mongodb://localhost:27017`
2. Sao chép `.env.example` thành `.env` nếu file `.env` chưa có
3. Điều chỉnh các giá trị trong `.env` nếu cần
4. Chạy `npm install`
5. Chạy `npm start` rồi mở http://localhost:3000

Cấu hình ứng dụng được nạp từ file `.env`:
- `PORT`: cổng chạy ứng dụng
- `MONGO_URI`: chuỗi kết nối MongoDB
